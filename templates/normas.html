Poke-Guess

Reglas del juego:

Poke-Guess es el Tutti Frutti (también conocido como Stop o Alto el lápiz) llevado al mundo Pokémon.

  1. La partida tiene {{ motor.RONDAS }} rondas, aunque al crearla se pueden elegir entre {{ motor.OPCIONES_RONDAS[0] }} y {{ motor.OPCIONES_RONDAS[-1] }}. En cada una se sortea un tipo: agua, fuego, dragón...
  2. Cada jugador escribe en secreto un Pokémon de ese tipo antes de que se acabe el tiempo.
  3. Respuesta que nadie más ha puesto: {{ motor.PUNTOS_UNICA }} puntos.
  4. Respuesta repetida con otro jugador: {{ motor.PUNTOS_REPETIDA }} puntos.
  5. Si todos ponéis el mismo: {{ motor.PUNTOS_TODOS_IGUAL }} puntos.
  6. Si el Pokémon no existe, no es de ese tipo o se acaba el tiempo: 0 puntos.

Gana quien sume más puntos al final. ¡Piensa en Pokémon que no se le ocurran a nadie!

Formas de jugar:

  • Online: cada uno en su móvil. Uno crea la sala y comparte el código de 4 letras. Todos responden a la vez y tenéis {{ salas.SEGUNDOS_RONDA }} segundos por ronda. Con cuenta, la partida suma para el ranking.
  • Entrenamiento: tú contra 1, 2 o 3 bots, en dificultad fácil, normal o difícil. No cuenta para el ranking.
  • Frenesí (dentro del entrenamiento): rondas sin fin y cada vez con menos tiempo. Tienes {{ salas.VIDAS }} vidas y pierdes una con cada respuesta que no puntúa.
  • En un solo móvil: os lo vais pasando por turnos, con {{ motor.SEGUNDOS_POR_TURNO }} segundos cada uno.
